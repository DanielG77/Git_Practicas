Resum del projecte

Aquí presentem una síntesi de l'organització i l'estat del projecte (sense incloure l'enunciat complert). Equip: usuari1 (repo i proves), usuari2 (contingut i atributs), usuari3 (estils i release).

  • Branques principals: main (producció), develop (desenvolupament)
  • Features: feature/contingutHTML, feature/atributsHTML, feature/estilsCSS
  • Hotfix: hotfix/milloresV_1_0
  • Release: v1.0 (usuari3) i tags de patch si s'han creat

Procés realitzat (resum)

Treball seguint la metodologia Git Flow: features desenvolupades en rames feature/..., una release/1.0 etiquetada i un hotfix/milloresV_1_0 aplicat a main. Els commits segueixen el format suggerit a la pràctica (ex.: usuari2: feat(contingutHTML): ...).

Per al detall lineal del procés (comandes + captures), mira la secció Captures i baixa l'informe PDF si ho necessites.
