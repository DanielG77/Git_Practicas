# Práctica: Sistema de control de versiones

Pequeño proyecto de ejemplo para practicar flujo de trabajo con **git / git-flow** y publicar documentación en **GitHub Pages**.

## Qué contiene
- `index.html`, `css/styles.css`, `js/app.js` — demo con 3 secciones:
  - **Modificar contingut HTML** (usuari2)
  - **Modificar atributs HTML** (usuari2)
  - **Modificar estils CSS** (usuari3)
- `docs/` — documentación para publicar en `gh-pages`.
